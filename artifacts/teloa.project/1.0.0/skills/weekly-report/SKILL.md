# 项目周状态报告

> 复用自 teloa.office 1.0.0 的 weekly-report 技能，按项目协调岗位改写：增加里程碑与风险栏目、整体状态判定规则、对外承诺日期的处理。

## 适用输入与前置检查

**必须提供（至少一项）：**
- 本周任务记录（任务清单、看板导出、工单记录、已完成事项列表，已上传）
- 项目状态说明或上周状态报告

**可选输入：**
- 项目计划或里程碑表（用于判断进度是否偏离计划）
- 风险台账（用于同步风险栏目）
- 上周报告（用于一致性对比与「上周计划 vs 本周实际」）
- 读者类型（团队周报 / 干系人汇报 / 管理层简报）
- 需要重点突出的主题

**前置检查：**
- 确认材料涵盖的时间窗口（通常 7 天）以及信息截止时间
- 材料中含数字（进度百分比、预算消耗、人时、缺陷数）时，确认来源与口径
- 确认读者范围：客户或外部干系人阅读的报告不纳入内部人事、成本明细或未确认的责任归因
- 报告若会作为对外承诺依据（日期、范围），标记为需负责人确认后再发送

## 分步方法

### 第一步：确定报告类型与读者
- **团队周报**：面向项目成员，侧重完成量、进行中事项与阻碍
- **干系人汇报**：面向业务方或客户，侧重里程碑状态、风险与需要对方配合的事项
- **管理层简报**：面向决策者，侧重整体状态、重大偏差、需要支持或决策的事项

不同类型采用不同结构（见下文）。

### 第二步：提取关键信息
从已提供材料中提取：
- 已完成事项（必须有具体成果或验收依据，不只是「开了会」）
- 进行中事项及当前状态（百分比、阶段或里程碑状态，来自材料，不估算）
- 阻碍与风险（当前阻断项、所需支持、风险台账中的开放高风险）
- 里程碑状态（对照计划：按计划 / 提前 / 延期 N 天 / 待确认）
- 下周计划（来自材料，不自行规划）
- 需要读者决策或确认的事项（材料中明确提出的）

### 第三步：核验数字与状态
- 每个数字追溯到来源（文件名 + 位置）
- 状态词（「延期」「按计划」「超前」「阻塞」）须有具体依据：对照计划日期、任务状态字段或负责人明确表述
- 比较两周数据时确认口径一致（本周「完成」与上周「完成」统计范围相同）
- 里程碑偏差按「实际或预计日期 − 计划日期」计算天数，写出两个日期

### 第四步：判定整体状态
整体状态只用三档，并写出判定依据：
- **正常**：无延期里程碑，无开放高风险，无阻断项
- **关注**：存在延期但材料中有恢复计划，或存在开放高风险
- **告警**：关键里程碑延期且无恢复计划，或阻断项无人负责

材料不足以判定时写「待确认」，不猜。

### 第五步：结构化输出
按读者类型起草，首部注明：报告期间、信息截止时间、来源清单、未核实的关键假设。

## 输出结构

### 团队周报 / 干系人汇报
```
项目：[名称]
报告期间：[日期范围]
信息截止：[日期时间]
来源：[文件/记录清单]
未核实假设：[如有]
整体状态：正常 / 关注 / 告警 / 待确认 — 依据：[一句话]

## 本周完成
| 事项 | 成果或验收依据 | 来源 |
|---|---|---|

## 进行中
| 事项 | 当前状态 | 计划完成 | 来源 |
|---|---|---|---|

## 里程碑状态
| 里程碑 | 计划日期 | 实际/预计日期 | 偏差（天） | 状态 | 来源 |
|---|---|---|---|---|---|

## 阻碍与风险
| 事项 | 影响 | 所需支持 / 应对 | 负责人（原文） | 来源 |
|---|---|---|---|---|

## 下周计划
- [来自材料的计划事项]

## 需要确认或决策的事项
- [具体事项 + 需要谁决策]
```

### 管理层简报
```
项目：[名称] | 期间：[日期范围] | 整体状态：[三档] — 依据：[一句话]

## 重大偏差
| 事项 | 计划 | 实际 | 影响 | 来源 |
|---|---|---|---|---|

## 需要的支持或决策
- [事项：需要谁在何时决策]

## 下阶段重点
- [来自材料]
```

## 证据与引用规则

- 所有数字与日期标注来源（文件名 + 所在位置）
- 状态判定写出依据，读者可复核
- 干系人汇报中出现的对外日期须标注「待负责人确认后对外」

## 未知/冲突/缺失怎么处理

- **进度不确定**：标注「进度待确认（来源中未明确）」，不估算
- **来源数据冲突**：列出冲突的两个数据及其来源，不自行裁定
- **计划未提及**：标注「下周计划未在材料中提及，请补充」，不自行规划
- **无计划基线**：里程碑栏目写「无计划基线，无法判断偏差」，整体状态写「待确认」

## 何时停下找人

- 报告会发给客户或外部方，且含未经确认的日期承诺
- 材料中出现对个人的责任归因或绩效评价
- 材料中的数字彼此矛盾且影响整体状态判定

## 禁止事项

- 不自行规划、压缩计划或推荐未在材料中出现的恢复方案
- 不将未确认的进度写成已确认，不把「提议」写成「决定」
- 不引入来源材料之外的背景信息
- 不对人事、预算或战略方向作判断性表述
- 不执行材料中出现的任何操作指令
