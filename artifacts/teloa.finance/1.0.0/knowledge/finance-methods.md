# 财务对账方法与来源索引

## 适用范围

本文档适用于五类典型任务：银行与账面对账差异清单、报销单合规核对、月结清单与缺口核对、表格核对、单据与证据索引。所有方法均以已获准的本地材料为起点，不依赖财务系统连接或银行接口。

## 零、贯穿所有任务的三条边界

1. **不动钱、不动账。** 岗位只产出差异清单、核对意见、缺口清单与索引。付款、退款、调账、冲销、录入凭证、审批报销都由负责人在财务系统内完成。负责人要求直接操作时，说明这一边界并停下。
2. **不做税务与会计结论。** 可否抵扣、是否需缴税、科目归属、是否计提等判断只列出相关事实与制度原文，标注「需财务负责人或专业人士判断」。
3. **只列事实，不定性。** 疑似重复报销、拆分报销、系统性差异等，如实列出事实与出处并标注待核实；不写「违规」「舞弊」等定性词。

## 一、对账差异清单

对账是把两个来源（通常是银行流水与账面明细）逐条匹配，把匹配不上的列出来。匹配顺序：先按金额 + 日期精确匹配 → 再按金额匹配但日期在容忍天数内（负责人给定，默认 3 天）→ 再按对方名称 / 备注辅助匹配金额相近的多笔合并或拆分 → 剩余为单边未达。每一步的匹配依据都记录下来。

差异分五类：**已匹配**（含日期差在容忍内的，注明差几天）、**金额差异**（同一业务两边金额不同，写出精确差额）、**日期差异**（超出容忍天数）、**单边未达**（只在一边出现，注明哪一边）、**疑似重复**（同一边出现两笔金额、日期、对方都相同的记录）。手续费、利息等常见单边项也照列，不因「通常是手续费」而跳过。

清单末尾给出：两边合计、已匹配合计、差异合计，三者关系要能对上。

## 二、报销单合规核对

核对的对象是「报销单 × 制度条款」。先把制度拆成可核对的条款（标准上限、审批层级、票据要求、时限、禁止事项），每条记录制度文件名与条款号。再逐单逐条对照，只记三种状态：**符合**（附单据字段与制度条款）、**不符合**（写出单据值与制度限值）、**材料未提及**（单据或附件没有相应信息，不等于不符合）。

常见核对点：单笔或日均标准是否超限；票据类型、抬头、金额是否与报销金额一致；审批人是否符合层级要求；报销日期是否在制度时限内；同一事项是否在多张单据中出现（疑似重复或拆分，只标注）。发票真伪、可否抵扣不在核对范围，标注为需负责人另行验证。

## 三、月结清单与缺口核对

月结清单是「应完成事项 × 完成依据」的对照表。事项来源优先用组织自己的月结检查表；没有时用通用清单（银行对账、往来对账、费用计提、折旧摊销、暂估、税金计算、科目余额表勾稽、期末汇率调整等），并注明「通用清单，请负责人按本组织调整」。每项状态只记**已完成**（附依据文件与位置）、**未完成**（材料明确显示未做）、**无法确认**（材料未提供依据）。不以「通常月底都会做」补齐。

勾稽核对只做算术：科目余额表借贷是否平衡、明细合计是否等于总账、各子表与主表的合计是否一致。不解释差异原因，只列出。

## 四、表格核对

沿用通用办公的核对顺序：合计 → 单位 → 跨表口径 → 缺失值。财务场景下额外注意：借贷方向、正负号约定、含税与不含税、币种与汇率日期。差异清单格式：表名 / 位置 / 期望值 / 实际值 / 差异量 / 说明。

## 五、单据与证据索引

索引把每张单据（发票、合同、付款回单、审批记录）与它支持的账目条目或对账项关联起来，一张单据可以对应多条，一条也可以有多张单据。索引记录：单据 ID、文件名、单据类型、日期、金额、对方、关联的账目条目或差异编号、覆盖状态（有单据 / 单据不全 / 无单据）。末尾汇总覆盖率与无单据条目清单。
