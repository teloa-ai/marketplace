# 单据与证据索引

> 本技能复制自 `teloa.grc` 方案的 `evidence-index`（1.0.0，所属方案 1.0.2）并按财务场景调整，调整点见方案 knowledge 的「复用技能来源索引」。

## 概述

单据与证据索引是把已收集的财务单据（发票、合同、付款回单、审批记录、对账函等）与它们所支持的账目条目或对账差异项系统性关联的清单。本技能用于建立新索引或更新已有索引，供月结、审计准备与差异追查时快速定位依据。

## 前置条件

- 已提供的单据文件列表（文件名、类型、日期、金额、对方）
- 需要关联的目标清单（账目明细、对账差异清单或报销单批次，至少一个）
- 单据编号规则（如有；没有时按本技能规则编号）

## 单据分类

### 交易单据

| 类型 | 示例 |
|---|---|
| 发票 | 增值税专用 / 普通发票、电子发票、境外 invoice |
| 合同与订单 | 采购合同、销售合同、订单确认 |
| 收付凭据 | 银行付款回单、收款通知、支付平台账单截图 |
| 物流与验收 | 签收单、验收单、入库单 |

### 内部记录

| 类型 | 示例 |
|---|---|
| 审批记录 | 费用审批单、付款审批流截图 |
| 对账确认 | 对账函、客商余额确认 |
| 计算依据 | 计提表、折旧表、分摊表 |
| 说明文件 | 差异说明、情况说明、邮件往来（已脱敏） |

单据影像中的银行卡完整卡号、身份证号不摘录，索引只记录后四位或「已隐去」。

## 索引建立步骤

### 第一步：单据清查

列出所有已提供的单据文件：
```
单据 ID：DOC-001
文件名：inv-20260812-供应商甲.pdf
类型：增值税专用发票
日期：2026-08-12
金额：12,600.00 元（含税）
对方：供应商甲
提供人/部门：采购部
备注：抬头为公司全称
```

字段从单据原文读取；读不出的写「未识别」，不猜测。

### 第二步：关联目标条目

对每张单据，映射到它支持的账目条目、对账差异项或报销单：

```
单据 ID：DOC-001（供应商甲发票 12,600.00 元）
关联条目：
  - 账面明细 2026-08 第 37 行（应付账款 — 供应商甲 12,600.00 元）— 金额、对方、日期一致
  - 对账差异清单 #5（仅 B 有，12,600.00 元）— 金额一致
```

关联依据只用金额、日期、对方、单据号等可核对字段；金额不一致但疑似同一业务的写「疑似关联，差额 X 元」，留待负责人确认。

### 第三步：覆盖状态统计

对目标清单中的每个条目统计单据覆盖：
- **有单据**：至少一张单据金额、对方一致
- **单据不全**：有关联单据但金额不一致、缺发票或缺审批等制度要求的类型（制度要求来自负责人提供的清单，不自行假定）
- **无单据**：没有任何关联单据

### 第四步：缺口识别

列出无单据与单据不全的条目：
```
无单据条目：
- 账面明细第 52 行（管理费用 — 办公用品 860.00 元）：无发票、无审批
单据不全条目：
- 账面明细第 37 行：有发票，缺付款回单
```

## 输出：单据索引表

| 单据 ID | 文件名 | 类型 | 日期 | 金额 | 对方 | 关联条目 | 关联依据 | 覆盖状态 | 备注 |
|---|---|---|---|---|---|---|---|---|---|

每行记录一张单据与一个条目的关联（一张单据可有多行）。

## 输出：覆盖汇总

```
单据总数：X 张（已关联：X 张，未关联到任何条目：X 张）
目标条目总数：X 条
  有单据：X 条（Y%）
  单据不全：X 条（Y%）
  无单据：X 条（Y%）
未关联单据清单：[单据 ID 列表，可能属于其他期间或其他清单]
```

## 更新机制

当以下情况发生时，需更新索引：
- 新月结周期开始
- 对账差异清单更新
- 新单据补齐
- 审计或检查前

## 草案标注

索引首行必须注明：
> 草案，待负责人审阅确认后方可使用。单据真实性、关联关系与制度要求的完备性需由负责人核实。

## 局限说明

- 本索引基于已提供的文件列表，不对未提供单据的存在性做判断
- 不判断发票真伪、可否抵扣或税务处理
- 不判断单据是否满足会计入账要求，不给会计处理建议
- 关联依据只用可核对字段，疑似关联由负责人确认
- 不修改任何账目数据，不代为补录单据
