## 材料一：用人部门需求说明（文件名：cs-manager-需求-2026-09-18.md）

我们客户服务部要新开一个客户成功经理岗位，主要是接手 B 端付费客户上线后的服务。具体来说：

1. 负责 20 家左右重点客户的上线陪跑和季度回访，客户续约率是核心指标。
2. 收集客户使用中的问题和需求，整理成周报给产品部。
3. 出现客户投诉或重大故障时，作为客户侧第一联系人协调内部资源。
4. 每季度给客户做一次使用培训。

要求：
- 做过 SaaS 或企业软件的客户成功、售后或实施，至少 3 年。
- 会用 Excel 做数据透视和基础分析，能自己拉续约率和活跃度报表。
- 沟通表达好，能独立跟客户高管开会。
- 最好 30 岁以下，精力好，能接受偶尔出差。
- 有 CRM 系统（Salesforce、纷享销客等）使用经验的优先。
- 有激情，认同公司文化。

汇报给客户服务部总监。工作地点上海。
