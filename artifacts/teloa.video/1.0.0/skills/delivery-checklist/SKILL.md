# 多规格交付与成片检查清单

## 用途

根据交付规格要求，生成多规格成片检查清单。无媒体执行环境时，清单作为交付文档；实际播放检查须有可用的渲染输出后由负责人执行。

## 输入

- 交付规格（规格名称、分辨率/比例、帧率、编解码器要求、响度目标、文件格式）
- 成片文件清单（规格名 → 文件名映射，可选；未提供时检查清单仅含规格要求，不含文件核对）
- （可选）渲染输出信息（文件大小、mediainfo 输出）

## 输出格式

每个规格一张检查表（Markdown 格式）：

```
## 规格：[规格名]（[分辨率] / [帧率] / [格式]）

| # | 检查项 | 预期 | 实测/核对结果 | 状态 |
|---|---|---|---|---|
| 1 | 首帧无黑帧起止 | 首帧有画面 | （负责人填写） | 待核 |
| 2 | 尾帧完整 | 尾帧有画面，无意外截断 | | 待核 |
...
```

状态值：待核 | 通过 | 不通过 | 不适用

## 检查项目

标准检查项（可按交付规格调整）：

1. 首帧无黑帧起止
2. 尾帧完整，无意外截断
3. 转场处无跳帧或画面撕裂
4. 字幕与画面同步（无明显提前或滞后）
5. 音画同步（无明显漂移）
6. 中间段无非预期黑帧（超过 0.5s 的黑帧）
7. 中间段无非预期静音段（超过 1s 的静音）
8. 文件可正常解码（格式与编解码器符合规格）
9. 响度符合交付规格（需响度测量工具；无工具时标注「待测」）
10. 文件命名符合交付约定

## 执行步骤

1. 根据交付规格列出所有规格版本
2. 为每个规格生成上述检查表，在「预期」列填入规格要求
3. 「实测/核对结果」列留空（由负责人播放核对后填写）；若已提供 mediainfo 输出则按技术参数预填
4. 汇总：总规格数量，列出需特别关注的检查项（如「响度测量需专用工具」）

## 边界

- 不自动播放或渲染视频
- 响度、帧率、编解码器数值验证须有 mediainfo/ffprobe 输出，无输出时标注「待测」
