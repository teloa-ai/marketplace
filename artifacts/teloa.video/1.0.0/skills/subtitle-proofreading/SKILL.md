# 字幕校对（时间轴、断句、错别字、品牌词）

## 用途

对已提供的 SRT 或 VTT 字幕文件进行结构化校对，输出问题清单和修订后的字幕文件草案。

## 输入

- 字幕文件（SRT 或 VTT 格式文本，直接粘贴或作为附件上传）
- 品牌词表（可选；未提供时可疑品牌词标注「待确认」）
- 全文校对目标（可选；如「以简体中文为准，无法律免责条款」）

## 输出格式

**一、问题清单**（按类型分组）

| 序号 | 类型 | 条目编号 | 原文 | 问题说明 | 建议修订 |
|---|---|---|---|---|---|

问题类型：时间轴重叠 | 断句错误 | 错别字 | 标点错误 | 品牌词错误 | 其他

**二、修订后字幕草案**（完整 SRT 或 VTT 文本，已应用建议修订）

## 执行步骤

1. **时间轴校对**：检查相邻条目出点 > 下一条入点（时间重叠），以及第一条入点是否为负值
2. **断句校对**：检查单条是否切断完整语义单元（句子中间断开，或标点在下一条首部）
3. **文字校对**：错别字（同音/形近字）、简繁混用、全半角混用
4. **品牌词校对**：对照品牌词表核查产品名、公司名的拼写与大小写
5. 汇总统计：各类问题数量，标注「已修订」与「待人工确认」数量
6. 输出修订后完整字幕文件草案，修订处用注释或括号标注变更来源

## 边界

- 只修订文字内容，不重新生成时间码（时间码需音画对齐验证由负责人完成）
- 品牌词词表未提供时，不主动猜测正确拼写，仅标注「待确认」
