# 素材盘点

## 用途

对已提供的视频素材清单或文件进行逐项登记，输出结构化索引表，供后续剪辑方案与转写整理直接引用。不删除、移动或上传任何原始文件。

## 输入

- 素材文件清单（文件名列表、压缩包目录、或负责人口述的文件名）
- （可选）媒体信息输出（mediainfo 或 ffprobe 命令结果）
- （可选）拍摄记录或场记单

## 输出格式

Markdown 表格，字段：序号 | 文件名 | 格式/编解码器 | 时长 | 分辨率 | 帧率 | 录制时间 | 内容描述 | 备注

规格信息未知时字段标注「待确认」；内容描述由负责人提供或根据文件名推断，推断时明确标注来源。

## 执行步骤

1. 逐项列出已提供的素材文件名，确认无遗漏
2. 填写已知的技术规格（来自媒体信息或场记单）；未知字段标注「待确认（需 mediainfo/ffprobe 输出）」
3. 根据文件名或场记单写入内容描述，推断时标注「推断自文件名，待确认」
4. 统计总素材数量、已知总时长与尚未确认的字段数量，写入摘要行

## 边界

- 不生成任何 FFmpeg 命令或渲染脚本
- 不访问未授权的媒体存储或网络素材库
- 不对素材做任何编辑判断（剪辑判断在粗剪方案步骤完成）
