# 带时间码转写整理

## 用途

对已提供的视频转写文本（来自转写工具或手动转写）进行整理，输出带开始时间码的分段文字稿，标注术语与品牌词，并记录低置信度段落。

## 输入

- 转写工具输出文本（含或不含时间码）
- 品牌词表或术语表（可选；未提供时可疑术语标注「待确认」）
- 原始视频文件（可选；用于比对明显对不上的时间段）

## 输出格式

逐段格式：

```
[HH:MM:SS] 文字内容（关键术语已标注）
```

低置信度段：

```
[HH:MM:SS–HH:MM:SS] [识别不清] 可能是：XXX （置信度低，待人工核听）
```

文字稿末尾附「品牌词与术语清单」：已确认、待确认两类。

## 执行步骤

1. 按时间顺序整理段落，每段保留开始时间码
2. 对照品牌词表修正拼写；词表未提供时，疑似专有名词标注「[术语？]」
3. 标注明显识别错误（上下文明显不通时），记录原文与推断文本
4. 统计：段落数、低置信度段落数、未确认术语数

## 边界

- 不删改转写工具的原始时间码，仅在整理后文稿中呈现
- 不对视频内容做剪辑判断
- 不访问未授权的原始视频存储
