# 应用安全方案 (Application Security Solution)

面向应用安全团队的代码审计、安全设计评审、威胁建模、扫描结果复核与 Web 渗透测试协作方案。

A solution for application security teams covering code audit, security design review, threat modeling, scan result triage, and web penetration test collaboration.

---

## 现在可做（What you can do now）

上传代码、设计文档或扫描报告后即可开始以下任务，无需任何在线连接：

- **代码审计**：对已提供的代码快照，识别注入、认证与会话、访问控制/IDOR、SSRF、反序列化、路径遍历、XSS、密钥与配置、依赖等漏洞类别，输出带文件行号、调用链证据、CWE 编号的发现报告。
- **安全设计评审**：按 OWASP ASVS 5.0.0 章节编号对照设计文档，输出逐条评审结论（已满足/有条件满足/证据不足/需整改）。
- **威胁建模**：从系统描述建立数据流图和信任边界，按 STRIDE 逐元素分析威胁，输出威胁台账、缓解措施和残余风险说明。
- **扫描结果复核**：对 SAST/SCA/DAST 工具输出去重、判定误报、给出 P0–P3 优先级建议。
- **修复验证**：对修复后版本逐条核对发现是否完整闭环，标注残余不确定性。
- **Web 测试协作**：准备 WSTG v4.2 测试计划（授权确认清单 + 按编号的测试用例）或整理测试发现记录。

---

## 还需你提供（What you need to provide）

- **代码审计**：代码快照（固定版本或提交哈希）、审计范围说明、威胁边界描述。
- **设计评审**：架构文档或 API 契约（注明版本）、数据分类说明、权限矩阵。
- **威胁建模**：系统功能描述、主要数据流说明（来源、组件、存储、去向）。
- **扫描复核**：扫描工具输出（SARIF/CSV/JSON），注明工具名称与版本。
- **修复验证**：原始发现报告、修复后代码快照（固定版本）。
- **Web 测试协作（测试计划）**：书面授权范围（目标域名/IP/应用）、测试环境说明、排除范围、禁止动作、停止联系人。
- **Web 测试协作（发现整理）**：测试人员提供的原始发现记录（含请求/响应摘要）。

如需持续读取扫描系统、代码仓库或工单平台，须另行配置对应连接。

---

## 会请求的权限（Permissions that may be requested）

- **只读**：读取你上传的代码文件、文档和扫描报告（默认）。
- **可选**：代码仓库只读连接（用于持续跟踪代码变更）。
- **可选**：扫描系统或工单平台只读连接（用于持续复核新产生的扫描结果）。

以下权限**不在本方案范围内**，须独立授权后另行处理：
- 向代码仓库推送（写）
- 向外部工单系统提交（写）
- 执行主动渗透测试或主动扫描
- 访问生产系统或生产数据库

---

## 已验证范围（Verified scope）

本方案仅交付可追溯的分析与草案，基于已提供的静态材料。以下范围**尚未通过真实集成验收**：

- 与真实 SAST/SCA/DAST 平台的在线连接
- 主动渗透测试执行
- 代码仓库自动拉取与实时扫描

---

## 不包含（Not included）

- 主动渗透测试（漏洞利用验证、模糊测试、主动扫描）——须在独立授权范围内由授权人员执行
- 代码提交或仓库写操作
- 对外提交工单或通报
- 自动取得任何合规认证资质
- 替代客户自行判断适用的合规标准与版本
