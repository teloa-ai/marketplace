# 威胁建模输入样例

## 系统描述

**系统名称**：SimplePay（虚构支付处理系统）  
**功能**：允许注册用户上传商品列表、创建支付订单、通过第三方支付网关完成付款。

## 主要数据流

1. **用户 → 前端应用**：通过 HTTPS 提交注册信息（用户名、邮箱、密码）和订单（金额、商品 ID）。
2. **前端应用 → API 服务**：通过 JWT 认证的 REST API 提交支付请求。
3. **API 服务 → 支付网关**（外部服务）：通过 HTTPS 调用第三方支付 API，传递订单金额和商户密钥。
4. **API 服务 → 数据库**：读写用户信息、订单状态。
5. **支付网关 → API 服务**（回调）：通过 Webhook 通知支付结果，传递交易 ID 和状态。

## 用户角色

- **普通用户**：注册后可创建和查看自己的订单
- **管理员**：可查看所有订单和用户信息（通过独立管理端口）

## 已知安全控制

- 前端通过 HTTPS 通信
- API 服务使用 JWT 验证用户身份
- 数据库仅允许内部网络访问

## 建模范围

- **范围内**：前端应用、API 服务、数据库、支付网关 Webhook 回调
- **范围外**：第三方支付网关内部实现、CDN、DNS 基础设施
