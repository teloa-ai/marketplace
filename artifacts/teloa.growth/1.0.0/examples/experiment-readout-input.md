# 实验结论整理输入材料（合成样例）

**产品：** 团队协作工具「协同板」

## 文件 1：实验计划（experiment-plan-EXP-042.md，2026-08-28 定稿）

- **假设**：把引导流程从 5 步缩短为 3 步并在第 2 步直接创建示例项目，能提高新用户 7 日激活率。
- **变体**：对照组 = 现有 5 步引导；变体组 = 3 步引导 + 自动创建示例项目。
- **分流比例**：50% / 50%，按用户 ID 哈希分流。
- **主指标**：7 日激活率 = 注册后 7 日内完成「创建首个项目」的用户 ÷ 组内用户，期望上升。
- **护栏指标**：
  - G1 引导流程完成率（完成全部引导步骤的用户 ÷ 组内用户）：变体不得低于对照 1 个百分点以上
  - G2 7 日内提交工单率（注册后 7 日内提交至少 1 张工单的用户 ÷ 组内用户）：变体不得高于对照 0.2 个百分点以上
- **计划周期**：2026-09-01 至 2026-09-14（14 天）。
- **每组最小样本量**：4,000 用户。
- **决策规则**：同时满足以下三条视为符合放量条件：(1) 主指标绝对提升 ≥ 2 个百分点；(2) 分析平台给出的双侧 p 值 < 0.05；(3) 所有护栏未越线。
