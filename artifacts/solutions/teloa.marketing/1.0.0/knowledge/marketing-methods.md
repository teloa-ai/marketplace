# 内容运营方法与来源索引

## 适用范围

本文档适用于品牌内容生产链路的五个环节：选题研究、多渠道改写与适配、品牌事实核对、发布包整理与发布复盘。所有方法以已提供的品牌材料为起点，不依赖实时爬取或账号私密数据。

## 一、选题研究

选题应同时满足：与品牌定位一致、与目标受众的当前关注点相关、与负责人提供的方向一致。每个选题方向保留：调研来源（已提供材料中的依据）、目标受众描述、核心价值主张、预期渠道。

选题来源只取已提供的材料和公开渠道的信息（如负责人上传的市场调研报告、行业报告截图）。不从竞品后台、账号私密分析或未授权数据源取数。

## 二、多渠道改写与适配

各渠道**常见格式做法**（以下为行业通行实践，发布前以平台现行规则为准）：

| 渠道 | 常见字数范围 | 常见结构特点 |
|---|---|---|
| 微信公众号 | 800–3000 字 | 标题含情绪词或疑问，正文分段明确，结尾有引导互动或关注 |
| 小红书 | 标题 ≤30 字，正文 300–1000 字 | 口语化，大量换行，话题标签（#），首图重要 |
| 微博 | ≤140 字（超出转为长微博） | 简短、情绪化或具体、带图，话题标签 |
| 抖音脚本 | 视频时长 15–60 秒，脚本约 100–300 字 | 前 3 秒钩子明确，行动号召在结尾，口播友好 |
| LinkedIn | 300–1500 字 | 专业语气，段落清晰，行动号召明确，标签少而精 |
| X（Twitter） | ≤280 字 / 帖 | 简洁直接，可用帖子串，引发转发比引发点赞更重要 |

改写必须根据渠道特性调整语气、长度与结构，不只是机械截取。品牌禁用词与核心事实保持与原稿一致。

## 三、品牌事实核对

品牌事实核对需要：
1. **产品事实库**（客户提供的官方产品参数、价格、功能描述等）
2. **禁用表述清单**（客户提供的不得出现的词汇、描述或对比声明）
3. **素材权利清单**（图片、视频的授权范围与有效期）

核对方法：
- 逐条比对稿件中的数字与产品事实库（不凭记忆补齐，来源缺失时标为待确认）
- 检查每条禁用表述是否出现
- 确认所用素材在清单中有明确授权记录，且授权期限在发布日期之内

AI 生成的图文内容需按平台要求标识（平台标识要求以平台发布时的现行规则为准）。

## 四、发布包

发布包是将稿件交给负责人发布的完整套件，包含：
- 目标渠道与账号说明（如「微信公众号：[公众号名称]，预计发布日期 2026-XX-XX」）
- 稿件正文（可直接复制粘贴的格式）
- 素材清单（文件名、尺寸规格、授权说明）
- 建议发布时间（来自已提供的数据或行业通行建议，标注来源）
- 发布检查单（格式是否符合渠道规范、事实是否已核对、素材是否齐备）

发布包的状态区别：草稿 ≠ 已准备发布 ≠ 已发布。不在发布包中声明"发布成功"。

## 五、发布复盘

复盘框架包含：
- 发布内容摘要（渠道、时间、核心主题）
- 数据指标（来自客户提供或连接的数据，标注来源与统计窗口）
- 与预期目标的对比（来自已设定的目标，不自行设定目标）
- 归因分析（仅基于已有数据，不猜测不可观察的原因）
- 下一步调整建议

无真实曝光/点击/转化数据时，复盘框架只提供结构与待填写的数据槽，不用虚构数据填充。
