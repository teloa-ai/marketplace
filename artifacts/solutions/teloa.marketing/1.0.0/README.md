# 新媒体内容运营 / Content Marketing

面向品牌内容生产与复盘的 Teloa 官方行业方案：选题研究、多渠道改写与适配、品牌事实核对、发布包整理与发布复盘。

A Teloa official solution for brand content production and review: topic research, multi-channel adaptation, brand fact checking, publish pack preparation, and post-publish review.

---

## 现在可做

上传品牌材料后，岗位可以：

- **选题研究**：基于已提供的品牌材料输出选题方向清单与受众画像草案，每个方向标注品牌关联性与依据来源
- **多渠道改写与适配**：将原始稿件改写为公众号、小红书、微博、抖音脚本、LinkedIn、X 等渠道版本；各渠道格式约束为行业常见做法，发布前以平台现行规则为准
- **品牌事实核对**：逐条核查稿件中的产品数据点、禁用表述与素材权利，输出已核实/待确认/存疑三类清单
- **发布包整理**：将已完成稿件打包为含渠道说明、稿件正文、素材清单与发布检查单的发布包（输出为草案，发布须你操作）
- **发布复盘**：基于你提供的指标数据输出复盘报告；无数据时只输出框架与数据槽，不填虚构数字

---

## 还需你提供

- **品牌材料**：品牌手册、产品事实库、禁用表述清单、素材权利清单（岗位只核查你提供的内容，不访问未授权的账号后台或网络来源）
- **目标渠道与账号信息**：岗位不知道你使用哪个渠道和账号，需要你告知
- **发布目标与 KPI**：复盘分析基于你事先设定的目标，未设定则跳过达成率对比

---

## 会请求的权限

本方案第一版仅需要**读取你上传的文件**，不请求任何发布权限、广告权限或账号连接。

以下操作**不在本方案范围内**，须你手动操作：

- 在任何平台或账号发布内容
- 购买广告投放或推广
- 以账号名义回复互动
- 将稿件上传为平台草稿

微信公众号、抖音、小红书等平台的发布 API 权限因账号类型而异，本版本未验证这些连接，不声明已支持自动发布。

---

## 已验证范围

- 基于已上传文件的选题研究、多渠道改写、品牌事实核查、发布包整理均为第一版验证范围
- 账号连接（自动上传草稿、发布、互动）尚未在本版本中进行端到端验收
- 本方案标注为 `content-only`，待完成真实模型验收后更新状态

---

## 不包含

- 在任何平台自动发布内容
- 购买或管理广告投放
- 代账号回复互动或私信
- 读取账号后台的私密数据或分析数据
- 采集受保护的竞品数据
