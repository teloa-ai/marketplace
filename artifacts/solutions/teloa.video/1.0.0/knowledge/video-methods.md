# 视频剪辑方法与来源索引

## 适用范围

本文档适用于五个剪辑协作环节：素材盘点、带时间码转写整理、粗剪方案与剪辑单、字幕校对与多规格交付检查。所有方法以已提供的文件和清单为起点，不依赖媒体执行环境（无执行环境时交付计划文档与剪辑单，而非渲染成片）。

## 一、素材盘点

素材盘点从文件清单或已上传的文件中建立索引，记录：文件名、格式（容器/编解码器，如已知）、时长、分辨率、帧率、录制时间（如元数据可读取）、大致内容描述。

分辨率与帧率未在文件名中体现时，标注「规格待确认（需播放检查或 mediainfo 输出）」。素材盘点不删除或移动原始文件，只建立只读索引。

## 二、带时间码转写整理

转写整理的标准格式为逐段时间码 + 文字，精度通常为秒级（HH:MM:SS）。处理步骤：

1. 对照已提供的转写文本（或转写工具输出）修正明显的识别错误
2. 标注专有名词、品牌词、技术术语（来自负责人提供的词表，或标注为「术语待确认」）
3. 标注转写质量问题段落（如「[HH:MM:SS–HH:MM:SS] 识别不清，可能是：…」）
4. 分段输出可供剪辑参考的文字稿，每段保留开始时间码

转写文本来自第三方工具时，记录工具名称与使用的语言模型版本（如已知）；转写错误率较高时明确标注置信度。

## 三、EDL 风格剪辑单

剪辑单（Edit Decision List, EDL）用于记录每个镜头的剪辑决策，本方案采用表格形式（EDL 风格），字段如下：

| 字段 | 说明 |
|---|---|
| 序号 | 连续整数，不跳位 |
| 素材 | 来源文件名（与素材盘点中的索引一致） |
| 入点 | 素材内起始时间码（HH:MM:SS） |
| 出点 | 素材内结束时间码（HH:MM:SS） |
| 时长 | 出点 - 入点（秒级计算） |
| 画面说明 | 描述画面内容（用于人工核查） |
| 声音说明 | 原声 / 旁白 / 背景音 / 静音 |
| 字幕 | 对应字幕内容（如有） |
| 转场 | 无 / 切 / 淡入淡出 / 其他 |
| 备注 | 颜色校正建议、B-roll 替换提示等 |

EDL 表格是计划文档，不等于已完成渲染。剪辑单交付后，实际导入目标剪辑软件（Premiere、DaVinci、Final Cut 等）须负责人操作并验证兼容性。

## 四、字幕校对

字幕文件通常为 SRT（SubRip）或 VTT（WebVTT）格式。校对步骤：

1. **时间轴校对**：检查相邻字幕段是否时间重叠（出点 > 下一条入点），入点是否早于零
2. **断句校对**：检查单条字幕是否切断完整语义单元（如句子中间断开，或标点在下一条字幕首部）
3. **文字校对**：错别字、简繁体混用、标点错误（如全半角混用）
4. **品牌词校对**：产品名称、公司名称的拼写与大小写（来自负责人提供的品牌词表）

字幕准确率目标由交付规范约定，本方法不声明通用的准确率标准。

## 五、多规格交付

成片交付通常需要多个规格（如 16:9 横屏全画质、9:16 竖屏短视频、1:1 方屏社交媒体）。交付检查覆盖：

- 首帧与尾帧完整（无黑帧起止、无意外截断）
- 转场处无跳帧或画面撕裂
- 字幕与画面同步（无明显提前或滞后）
- 音画同步（无明显漂移）
- 黑帧与静音段（中间段为异常，需标注）
- 文件可解码（格式与编解码器符合交付规范）
- 响度目标（来自交付规范，不声明通用标准）

无媒体执行环境时，检查清单作为交付文档，实际播放检查须有可用的渲染输出后由负责人执行。
