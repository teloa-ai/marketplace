## 不兼容变更

- 环境变量 `DB_URL` 更名为 `DATABASE_URL`；启动时只设置 `DB_URL` 会报错退出 — 升级步骤：在部署配置中把 `DB_URL` 重命名为 `DATABASE_URL`（值不变），重新部署并确认启动日志出现「config loaded」（docs/migration-1.4.md）（#209）

## 安全

- 升级依赖 xml-lite-parser 至 4.4.1，修复原型污染问题；使用 XML 导入的部署建议升级后重启（#212）
