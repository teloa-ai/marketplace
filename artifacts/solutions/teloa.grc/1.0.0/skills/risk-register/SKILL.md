# 风险台账

## 概述

风险台账是组织信息安全风险的结构化记录，用于追踪已识别风险的评分、处理措施和状态。本技能用于建立新风险台账条目或更新已有台账。

## 前置条件

- 差距分析报告（最常见的新风险来源）
- 资产清单或系统描述（如有）
- 现有风险台账（用于更新场景）
- 已知的威胁情报或安全事件记录（如有）

## 风险识别来源

| 来源 | 描述 |
|---|---|
| 差距分析 | 控制缺失或不足导致的风险敞口 |
| 安全事件 | 历史事件中暴露的风险 |
| 漏洞扫描 | 技术漏洞引起的风险 |
| 威胁情报 | CISA KEV 或行业威胁报告 |
| 业务变更 | 新系统、新业务或第三方合作引入的风险 |
| 审计发现 | 内部或外部审计发现的问题 |

## 风险评分方法

### 可能性评分（1–5）

| 分值 | 描述 | 参考频率 |
|---|---|---|
| 5 | 极高 | 几乎确定发生（过去 1 年内已发生或已有公开漏洞利用案例）|
| 4 | 高 | 很可能发生（过去 3 年内已发生或有活跃威胁）|
| 3 | 中 | 可能发生（有已知攻击向量）|
| 2 | 低 | 不太可能发生（需要特殊条件）|
| 1 | 极低 | 罕见（理论可行但实际极少发生）|

### 影响评分（1–5）

| 分值 | 描述 | 业务影响参考 |
|---|---|---|
| 5 | 极高 | 核心业务中断、重大数据泄露、监管处罚 |
| 4 | 高 | 重要系统受影响、敏感数据泄露 |
| 3 | 中 | 部分功能受影响、内部数据泄露 |
| 2 | 低 | 轻微影响、无敏感数据 |
| 1 | 极低 | 可忽略影响 |

### 风险评分矩阵

风险评分 = 可能性 × 影响
- 高风险（≥15）：须立即制定处理计划
- 中风险（8–14）：须在下一审计周期内处理
- 低风险（<8）：监控，纳入常规管理

## 风险处理选项

| 处理方式 | 描述 | 适用场景 |
|---|---|---|
| 缓解 | 实施控制措施降低可能性或影响 | 最常见，技术或管理措施可行 |
| 转移 | 通过保险或合同转移风险 | 残余风险可保险化或合同约束 |
| 接受 | 风险在可接受范围内，不额外处理 | 低风险或成本效益不合理 |
| 规避 | 停止引起风险的活动 | 高风险且无合理缓解方案 |

**注意**：风险接受须由授权人正式批准，不得自行填写"已接受"。

## 台账字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| 风险 ID | 是 | 唯一标识，如 RISK-001 |
| 风险名称 | 是 | 简短描述，如"SQL 注入导致数据库泄露" |
| 风险描述 | 是 | 详细描述威胁场景和潜在影响 |
| 资产 | 是 | 受影响的资产或系统 |
| 威胁类型 | 是 | 外部攻击/内部威胁/配置错误/供应链等 |
| 关联控制缺口 | 推荐 | 引用差距分析中的 GAP ID（如有）|
| 固有可能性 | 是 | 无任何控制时的可能性评分 |
| 固有影响 | 是 | 无任何控制时的影响评分 |
| 固有风险评分 | 是 | 固有可能性 × 固有影响 |
| 现有控制 | 是 | 现有缓解措施描述 |
| 残余可能性 | 是 | 考虑现有控制后的可能性评分 |
| 残余影响 | 是 | 考虑现有控制后的影响评分 |
| 残余风险评分 | 是 | 残余可能性 × 残余影响 |
| 风险级别 | 是 | 高/中/低 |
| 处理方式 | 是 | 缓解/转移/接受/规避 |
| 整改措施 | 推荐 | 具体整改行动（可引用 GAP 整改计划）|
| 建议负责人 | 占位 | 须负责人确认 |
| 目标完成日期 | 占位 | 须负责人确认 |
| 当前状态 | 是 | 开放/处理中/已关闭/已接受（接受须授权）|
| 最后更新日期 | 是 | 本次更新日期 |
| 备注 | 否 | 附加说明 |

## 输出结构

### 风险台账表

完整表格，包含上述所有字段。

### 风险摘要

```
台账更新日期：[日期]
风险总数：X 条
  高风险（开放）：X 条
  中风险（开放）：X 条
  低风险（开放）：X 条
  已关闭：X 条
  已接受（正式批准）：X 条
需立即关注：[高风险条目的风险 ID 列表]
```

## 草案标注

风险台账首行必须注明：
> 草案，待审阅确认后方可使用。风险评分基于提供的材料，需由负责人结合实际业务情况核实。风险接受须由授权人正式批准后方可标注"已接受"。

## 局限说明

- 风险评分依赖提供的业务背景和资产信息，评分准确性受输入质量影响
- 残余风险评分依赖对现有控制有效性的判断，未经测试验证的控制有效性属于假设
- 不包含定量风险评估（财务损失估算）
- 风险台账需定期复核（建议每季度），本技能仅处理当次更新
