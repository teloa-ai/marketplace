# 研究方法与来源索引

## 适用范围

本文档适用于四类典型任务：资料研究与可追溯简报、多源对比、知识库条目撰写、术语表整理。所有方法以你提供或授权的资料为起点；如授权使用检索连接器，只检索与研究问题直接相关的公开内容，并记录检索词、访问地址与检索日期。

## 一、共同规则

1. **每条结论标来源**：文件写「文件名 + 页码/章节/段落」，网页写「访问地址 + 检索日期」。没有来源的写「待核实」，不以常识或训练记忆补齐。
2. **区分三类内容**：已核实事实、基于事实的推断（写明依据哪些事实）、分歧或待核实项。三类分段陈述，不混写。
3. **写明时间边界**：首部写信息截止日期（取最新来源日期）与本次未覆盖的资料。网页内容随时可能变化，检索日期是结论有效性的一部分。
4. **不裁定来源优劣**：多个来源冲突时并列各方说法与来源；只有负责人事先给了优先级（如「以官方文档为准」）才据此归类，并在输出中声明。
5. **个人信息与未公开信息**：研究非必需时不引用；必须引用时在交付前标注，写入知识库前须负责人确认。

## 二、资料研究与简报

先把研究问题改写成一句可检验的目标句（回答什么、基于什么、给谁用）。逐份提取事实，精确引用数字，不四舍五入。分歧超过三处或涉及关键结论时，改用多源对比单独出表。结论只回答原问题，末尾给可执行的下一步核验动作（找谁、看什么、何时）。

## 三、多源对比

对比前固定维度（负责人指定或默认：定义/口径、数值或参数、适用范围与前提、时间或版本、限制与例外）。每个来源、每个维度都要填，填不出写「未提及」。结果归为一致、分歧、缺失三类；分歧项补「可能原因」（版本、口径、统计窗口、转述失真），标为推断。来源之间互相引用时标注引用链，避免把同一原始来源算成多个独立来源。

## 四、知识库条目

条目类型四选一（概念说明 / 操作流程 / 常见问题 / 决策记录），结构随类型固定。必须有「适用范围」且含一句「不适用于」。正文每条事实附来源编号；未经负责人确认的结论只能进「待确认」。维护人写占位，复核条件写清「什么变化发生时重新核对」。与已有条目冲突时并列差异表，不覆盖。

## 五、术语表

候选先各记一条，再合并缩写、全称、别名。定义优先取原文定义句；只有用法时写归纳定义并标「归纳」，附两处以上用例。同一术语定义冲突时并列，不选。个人姓名与客户名称不作术语。中英对照只取材料原有写法或负责人提供的对照。
