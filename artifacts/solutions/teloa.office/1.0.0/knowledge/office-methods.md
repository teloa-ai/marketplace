# 办公协作方法与来源索引

## 适用范围

本文档适用于以下四类典型任务：资料研究与可追溯简报、会议纪要与待办提取、周报与决策简报、表格核对。所有方法均以已获准的本地材料为起点，不依赖实时网络搜索或云端存储连接。

## 一、资料研究与简报

先把研究问题改写成一句可检验的目标句，记录范围、截止时间和读者。每条关键事实保留来源文件名、页码或段落。找不到来源时标为"待核实"，不以常识补齐。推断与事实分开陈述，说明它们依赖哪些事实。比较多个方案时用统一维度（目标、成本、风险、依赖、可逆性）。结论只回答原问题，并给出下一步核验事项。

## 二、会议纪要与待办

纪要必须严格区分三类内容：
1. **原文决议**：与会人明确同意的事项（保留原话或准确转述，不做润色性调整）
2. **建议/行动事项**：指定了负责人和截止日期的任务（owner 与日期缺失时保留空白，不自行补齐）
3. **缺席确认**：需要在会后向未参会人员单独确认的信息点

转写文本中发言人身份不确定时，记为"发言人[身份待确认]"，不凭声音特征或话题归属猜测。

## 三、周报与决策简报

周报结构：本周完成事项（含完成依据）→ 进行中事项与当前状态 → 阻碍与风险 → 下周计划 → 需要读者决策或确认的事项。

决策简报结构：背景（一句话）→ 决策问题（一句话）→ 选项对比（统一维度表格）→ 建议选项与理由 → 待确认的前提。

两类简报都要在首部写明：信息截止时间、主要来源清单、尚未核实的关键假设。

## 四、表格核对

核对顺序：先校验合计行（SUM 或公式是否覆盖所有数据行）→ 再校验单位（同一列的单位是否一致、是否有隐含单位换算）→ 再校验跨表口径（同一指标在不同表中的统计范围、时间窗口、分组是否一致）→ 最后标注缺失值（NA 与 0 是不同的，区别处理）。

差异清单格式：表名 / 列名 / 预期值 / 实际值 / 差异量 / 可能原因（如已知）。不在清单中隐藏任何差异，包括微小的格式差异（如日期格式不一致）。
