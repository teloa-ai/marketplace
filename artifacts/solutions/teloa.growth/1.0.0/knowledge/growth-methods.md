# 增长分析方法与来源索引

## 适用范围

本文档适用于产品运营分析员的四类典型任务：指标口径核对、实验结论整理、用户反馈归类、增长周报。所有方法以已获准的本地材料（指标词典、仪表盘导出、原始计数表、实验记录、反馈导出、运营动作记录）为起点，不依赖分析平台或搜索连接的实时访问；连接为可选项，接入后仍按同一规则处理。

## 一、共同原则

1. **数字可复算**：任何比率写出分子与分母，任何变化写出两个输入值与算式，读者不看原始文件也能验算。
2. **口径先于数字**：同一名称的指标先确认定义、时间窗口、分子分母与过滤条件一致，再比较数值；不一致时不算差异、不算变化，只并列。
3. **不裁定口径**：发现两个来源口径不同时，只描述差异与材料中的解释；哪一种是「正确口径」由数据负责人裁定。
4. **不推断因果**：指标变化与上线、活动之间的关系只在材料明确写出时转录并注明出处；否则写「材料未说明原因」。
5. **不替负责人决定**：实验只输出对预设决策规则的对照结果；反馈只输出主题与频次；全量、回滚、优先级、排期由负责人决定。
6. **个人信息隐去**：反馈原文中的邮箱、手机号、姓名、公司名、订单号在所有产出中替换为「[已隐去]」；数据表只使用聚合数字。

## 二、指标口径核对

核对顺序：抄词典建口径表 → 用原始计数复算 → 差异 = 报告值 − 复算值 → 只列候选解释（按另一口径复算能得到报告值才写「与 X 口径一致」）→ 跨来源并列 → 单位与时间窗口 → 缺失口径 → 自检。

精度规则：复算值保留到报告精度再多一位；报告值四舍五入到报告精度后与复算值一致视为「一致」，但保留复算值供查。

结论三档：通过 / 需核对方确认后再发布 / 存在口径冲突需数据负责人裁定。

## 三、实验结论整理

实验结论整理的对象是「计划里写了什么」和「结果里有什么」，不是「实验成功了没有」。

固定顺序：抄录设计（假设、变体、分流、主指标、护栏、周期、样本量、决策规则）→ 执行核对（周期、样本量、分流比例；分流偏差 > 1 个百分点标待确认）→ 主指标（比率、绝对差、相对差）→ 护栏（用未四舍五入的差异与阈值比较并写算式）→ 决策规则逐条判定 → 结论三选一：符合 / 不符合 / 无法判定预设放量条件 → 非预设观察单列 → 需负责人决策。

显著性：p 值、置信区间只转录分析平台或统计工具给出的数值并注明来源；本方案不自行计算。

## 四、用户反馈归类

固定标签：
- 类型六类：缺陷 / 可用性 / 功能请求 / 性能 / 定价与账单 / 其他
- 情绪三档：负 / 中 / 正，只看原文用词
- 严重程度三级（缺陷与性能）：阻断 / 严重 / 一般，原文不足则「待确认」

主题规则：一条反馈只归一个主题；主题至少 2 条，否则记入「单条反馈」；主题条数之和 = 有效条数；占比保留两位小数，合计因四舍五入落在 99.99%–100.01% 时注明。

需立即转交：安全漏洞、越权访问、数据泄露、支付风险、法律威胁、人身安全、未成年人相关，无论主题归属都单列。

## 五、增长周报

结构：首部（周期、对比周期、信息截止、来源、未核实假设）→ 核心指标表 → 实验进展 → 用户反馈要点 → 本周动作与结果 → 下周计划 → 需决策事项。

变化规则：计数指标写百分比变化 = (本周 − 上周) ÷ 上周；比率指标写百分点差 = 本周 − 上周；口径不一致或上周值缺失写「不可比」。本周口径核对指出冲突的指标，周报使用词典口径值并在备注列写出仪表盘值与待确认状态。

管理层简报只保留核心指标表、重大变化与实验结论、需要的决策。
