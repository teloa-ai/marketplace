## 文件 2：产品事实库（facts-v12.md，节选）

- §2.3 导出：Web 端支持导出为 Markdown 与 PDF。路径：笔记页右上角「更多」→「导出」→ 选择格式。移动端暂不支持导出。
- §4.1 同步：默认每 30 秒自动同步一次；手动同步：下拉笔记列表。若持续失败，先检查网络，再在「设置 → 账户 → 同步诊断」查看错误码。
- §4.2 已知问题：无与 3.4.x 同步相关的已知问题记录（截至 09-20）。
- §6.1 账户安全：陌生设备登录提醒由系统自动发送；客户可在「设置 → 账户 → 登录设备」查看并移除设备，并建议立即修改密码。安全事件由安全组处理。

## 文件 3：支持政策（policy-v5.md，节选）

- §3.1 一线可直接回答：功能使用、路径指引、已知问题告知。
- §3.2 必须升级：重复扣费、退款、赔偿请求（升级至账务组，2 个工作日内回复客户）；账户安全疑虑（升级至安全组，4 小时内响应）；客户提及投诉、法律、媒体。
- §3.3 回复中不得承诺退款结果、赔偿金额或修复时间。
- §5.1 SLA：P1 4 小时响应；P2 1 个工作日；P3 2 个工作日；P4 3 个工作日。
