## 文件 2：产品事实库（facts-v12.md，节选）

- §2.3 导出：Web 端支持导出为 Markdown 与 PDF。路径：笔记页右上角「更多」→「导出」→ 选择格式。移动端暂不支持导出。
- §3.2 修改登录邮箱：「设置 → 账户 → 修改邮箱」，输入新邮箱并完成验证码验证后生效；旧邮箱会收到变更通知。
- §5.1 文件夹分享：文件夹右键 →「分享」→ 选择成员并设置权限（可编辑 / 只读）。被分享者需要已有云笺账号。
- §7.4 编辑器：输入 / 唤出命令菜单，支持插入表格（/table）、待办（/todo）、代码块（/code）。
- §4.2 已知问题（截至 09-20）：Web 3.4 导出 PDF 时图片可能不显示，修复中。
