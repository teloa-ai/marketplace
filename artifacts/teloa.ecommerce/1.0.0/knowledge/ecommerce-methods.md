# 电商运营方法与来源索引

## 适用范围

本文档适用于电商运营协作员的五类典型任务：商品文案起草、商品文案事实与用语核对、活动日历编排、销量与销售额核对、买家评价分析。所有方法以已获准的本地材料为起点，不依赖店铺后台、平台商家中心或搜索工具的实时连接；连接为可选项，接入后仍按同一规则处理。

## 一、共同原则

1. **事实先于文案**：任何商品参数、效果、比较与荣誉表述都必须在商品事实表中有对应条目；没有条目就留占位符或标「待确认」，不以常识、网页搜索或竞品页面补齐。
2. **绝对化用语须有依据**：「最」「第一」「唯一」「顶级」「国家级」「全网销量冠军」等表述，只有事实表中附有可核验依据（检测报告、平台官方榜单截图、资质证书编号）时才保留，并在文案中写出依据；否则一律标「存疑」交负责人处理。依据来自广告法关于绝对化用语与虚假宣传的通行理解，最终判断由负责人或法务作出。
3. **效果、功效不越界**：食品、保健、日化、母婴、家居等品类涉及「治疗」「预防」「抗菌率」「降糖」等效果表述时，须以事实表中的检测报告或资质为限；事实表没有的不写。
4. **数字可复算**：销量、销售额、退款、占比、差额都写出来源与计算式，读者可用两个来源数字复算。
5. **口径并列不裁定**：多份表格口径不一致（含退款与否、按付款日或退款完成日、GMV 与买家实付、含运费与否）时，并列写出双方口径与数值，不判定哪份「正确」。
6. **不替负责人做动作**：改价、上下架、报名活动、发布文案、回复买家、承诺赔付、删除或隐藏评价，均只列为「待确认动作」。
7. **买家信息脱敏**：评价、客服记录中的昵称、订单号、手机号、地址不进入产出；引用原句时用评价编号定位。

## 二、商品文案起草

渠道拆分：详情页首屏（卖点 3–5 条 + 参数表）、详情页正文（场景、材质与工艺、参数、售后说明）、主图文案（每张 ≤12 字的短句 + 对应事实）、短视频口播（15–60 秒，分镜：画面 / 口播 / 字幕）、直播口播提纲（开场、卖点、答疑、下单引导）。

起草顺序：从事实表提取可用条目 → 判定每条能否直接引用、需换算或缺失 → 按渠道写 → 自检绝对化用语与效果表述 → 首部列出「使用的事实条目」与「未核实占位符」。

价格、优惠、赠品、库存、发货时效全部来自事实表或负责人书面说明；活动价与日常价分列，未确认的活动价写「[活动价待确认]」。

## 三、商品文案事实与用语核对

四张清单：产品事实核查（已核实 / 待确认 / 存疑）、用语扫描（绝对化用语、效果与功效表述、比较表述、诱导性表述如「限时」「仅剩」需有事实依据）、素材权利核查（图片、视频、字体、模特肖像的授权范围与有效期）、平台规则提示（材料中提供的平台规则条目，未提供则注明跳过）。

「已核实」必须引用事实表条目位置；「未在事实表中找到」只标「待确认」，不等于「事实有误」。

## 四、活动日历编排

节点来源三类：平台节点（报名截止、预热开始、正式开始与结束、结算）、店铺节点（新品上市、直播、内容发布）、准备工作（素材完成、库存到位、价格与优惠配置、客服话术更新）。

准备工作起点按「节点日期 − 准备时长」倒推，准备时长只取材料中的数字（如「素材制作 5 个工作日」）；材料没有的准备时长不推算，写「准备时长待确认」。

冲突四类：报名截止早于依赖它的准备工作完成；同一天多个节点争抢同一负责人或资源；活动 SKU 库存或备货到货日晚于活动开始；活动价低于事实表中的成本或最低价（只列出，不判定是否可接受）。

日历不代替报名与配置；所有需要在平台或后台操作的动作列在末尾「待确认动作」。

## 五、销量与销售额核对

核对顺序沿用表格核对：合计核验 → 单位核验（元 / 万元、件 / 箱、含税与否）→ 跨表口径核验 → 缺失值核验。电商场景补充：

- **口径要素**：统计口径（GMV / 买家实付 / 商家实收）、时间口径（按付款日 / 发货日 / 确认收货日 / 退款完成日）、退款口径（含退款订单 / 扣除退款 / 仅扣除已完成退款）、运费口径（含运费 / 不含）。表格未标明的记「口径未标明」。
- **净销售额**：只有在双方口径一致时才做减法；口径不一致时并列两个结果并写出计算式。
- **平台导出优先作为对照**，但不判定平台导出「正确」，手填日报的差异只列出，差异原因写「可能原因」并标「待核对方确认」。

## 六、买家评价分析

分类主题（可多选）：商品质量、与描述相符、尺寸与规格、包装、物流、客服与售后、价格与性价比、使用体验、其他。每条评价最少一个主题；同一评价可多主题，占比按「涉及该主题的评价条数 ÷ 评价总数」计算并注明多选。

星级作为情绪基线：1–2 星记负面，4–5 星记正面，3 星或文本与星级矛盾记「中性 / 待判读」并摘录原句。

安全类表述（人身伤害、过敏、异味刺鼻、异物、儿童误食、漏电、破裂伤人）单列「需负责人立即处理」，不与普通质量问题合并统计。

摘录原句附评价编号；不出现买家昵称与订单号；不生成回复文案，除非负责人另行要求，且标「草案，未发送」。
